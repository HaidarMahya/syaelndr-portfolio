# Syael Portfolio — V2

Static HTML portfolio. No npm install or build command is required.

## Deploy to Vercel
1. Import this folder/repository into Vercel.
2. Set Framework Preset to **Other**.
3. Leave Build Command and Output Directory empty (or use `.` as the output directory if prompted).
4. Deploy.

## Deploy to Netlify
1. Import this folder/repository into Netlify.
2. Set the Publish directory to `.`.
3. Leave the Build command empty.
4. Deploy.

The entry page is `index.html`; keep the `asset/` directory beside it so the portrait image path resolves.
